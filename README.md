# 🛠️ CRUD de Pessoas em JavaScript

Aplicação web para manipular registros de pessoas (CRUD: Create, Read, Update, Delete) usando HTML, CSS e JavaScript puro.

## ✨ Funcionalidades
- **Adicionar pessoa**: Insere nome, idade e profissão.
- **Consultar pessoa**: Busca por nome e exibe os dados.
- **Alterar pessoa**: Atualiza idade e profissão de um registro existente.
- **Excluir pessoa**: Remove um registro da lista.

## 🛠️ Tecnologias
- HTML5
- CSS3 (com animações e design responsivo)
- JavaScript (manipulação de arrays e DOM)
